# Dipak Das — SAP + IT Portfolio

## Open the website
1. Extract `sap_basis_portfolio.zip`.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Personalize before publishing
- Add your own professional photo as `assets/images/profile.jpg`.
- In `index.html`, replace the "Add your profile photo" placeholder with:
  `<img src="assets/images/profile.jpg" alt="Dipak Das" class="profile-photo">`
- Add this CSS to `assets/css/style.css`:
  `.profile-photo { width:100%; height:100%; object-fit:cover; object-position:center top; }`
- Replace `your-email@example.com` with your actual email address.
- Replace the LinkedIn and GitHub sample links with your profile URLs.
- Add your resume PDF at `assets/Dipak_Das_Resume.pdf`.
- Verify your employer name, dates, responsibilities and education details before publishing.

## Publish on GitHub Pages
1. Create a GitHub repository (for example `dipak-portfolio`).
2. Upload all files and folders from this project.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.
